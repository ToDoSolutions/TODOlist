# Soporte

| Qué necesitas | Dónde |
|---|---|
| Reportar un bug | [Issues](https://github.com/ToDoSolutions/TODOlist/issues) — indica backend/frontend y pasos para reproducir |
| Proponer una feature | Issue con plantilla "Feature request" |
| Duda de uso | Issue etiqueta `question` |
| Vulnerabilidad de seguridad | **No** abras issue público — ver [SECURITY.md](SECURITY.md) |

## Antes de reportar

- Entorno: Docker Compose es la vía soportada; indica versión
  (`CHANGELOG.md`) y si el bug es local o en instancia desplegada.
- Si el bug es de sincronización offline, adjunta qué hay en la cola
  pendiente del navegador.
- Bugs de permisos/roles: indica el rol del usuario afectado
  (ver `SECURITY.md` si aplica).
